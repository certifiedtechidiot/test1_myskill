# Project: Modern Luxury Construction & Real Estate Landing Page ("LEON HOME")

## Overview
A high-contrast editorial luxury real estate and architectural construction landing page featuring glassmorphic UI elements, layered typography with 3D foreground masking, full-width contrast bands, and an interactive featured projects showcase.

## Core Design System & Tokens
- **Palette**:
  - Primary Background: Pure White (`#FFFFFF`)
  - Contrast Band: Stark Black (`#000000`)
  - Headings / Editorial Text: Dark Charcoal (`#111111`) & Pure White (`#FFFFFF` on dark surfaces)
  - Body Text: Muted Gray (`#666666` on light, `#A1A1AA` on dark)
  - Glassmorphic Overlays: Translucent frosted glass `rgba(255, 255, 255, 0.15)` with `backdrop-filter: blur(12px)`
  - Dark Frosted Cards: `rgba(18, 18, 20, 0.72)` with `backdrop-filter: blur(16px)` and 1px crisp border `rgba(255, 255, 255, 0.14)`
- **Typography**:
  - Primary Headings & Hero Display: Cormorant Garamond / Playfair Display (High-contrast editorial serif)
  - Body & UI Labels: Plus Jakarta Sans / Inter (Clean geometric sans-serif)
- **Radii**:
  - Hero Container: `24px`
  - Content Cards: `16px`
  - Buttons & Badges: `9999px` (Full Pill)

## Technical Architecture
- **Structure**: Vanilla HTML5, semantic markup, modular CSS3 custom properties token system (`tokens.css`, `base.css`, `style.css`), high-performance zero-dependency JavaScript (`app.js`).
- **Pillars Enforced**:
  - Impeccable 4.8 (WCAG AA contrast, visible focus rings, full state coverage)
  - Hallmark (Anti-AI-slop, no un-tokenized values, composite layer transitions, screen-height hero)
  - AI Design Skill (1-offer-1-action, strict 4px/8px rhythm, balanced typography)
  - Taste Skill 2.5 (Screen rhythm, authentic architectural imagery, quiet micro-interactions)
  - OpenDesign (Elevation tokens, crisp borders, typographic scale)
